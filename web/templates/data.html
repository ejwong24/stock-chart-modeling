The static config/delisted_seed.txt partially mitigates this, but for full correction you need a paid data source (Polygon.io, EODHD, CRSP). See Flaws & Fixes #1 for details.
How are the tickers chosen?

The active universe is built from NASDAQ Trader's official symbol files (nasdaqlisted.txt and otherlisted.txt), filtered to common stocks (no ETFs, no test issues, no special character symbols). The delisted seed is a hand-curated list of well-known 2016–2026 delistings/bankruptcies.

Files: src/stock_chart/universe.py, config/delisted_seed.txt.

Why split-adjusted close prices?

The original document had to filter out 577 files with >50% one-day price moves because the raw close prices contained split-adjustment artifacts (e.g., a 1-for-10 reverse split looks like a -90% one-day move in unadjusted data). Setting auto_adjust=True in yfinance applies splits and dividends to the close column directly, eliminating this class of bug.
