Why It's Not Statistically Real

Even after honest reproduction, after realistic costs, after the falsification test — the best strategy still looks like it beats the random median by a few percent. Is that real? Three plain-language tools answer no.

Tool 1: Multiple-comparison correction (Deflated Sharpe)

If you flip a coin 7 times you have a 0.8% chance of getting 7 heads. Impressive. If you flip it 7,200 times you'll get 7-heads-in-a-row almost certainly. Not impressive.

The original paper tested 72 configurations and reported the best one. The Deflated Sharpe Ratio (Bailey & López de Prado, 2014) is the formal correction: it raises the bar proportionally to the number of trials.

Tool 2: Effective sample size (López de Prado)

The pipeline produced "1,104 trades." Sounds like a lot. But trades overlap massively: weekly entries, 40-day holds, ~25 positions open at any time. The trades aren't independent observations — they share holding periods.

A naive 95% confidence interval based on 1,104 trades might span ±2%. The honest interval based on 45 effective observations spans ±10%. The "edge" that looked obvious shrinks into the noise.

Tool 3: Block bootstrap confidence intervals

The Sharpe ratio is a single number. The block bootstrap asks: "if we'd run this experiment with a slightly different draw of the same data 10,000 times, how much would the answer wiggle?"

We resample chunks of daily returns (chunks of 40 days, matching the holding period) and recompute CAGR/Sharpe/max-DD for each resampled history. The result is a 95% interval, not a point estimate.

The original "100th percentile vs 100 random seeds" framing

The original paper's flag-planting claim was "the model ended in the 100th percentile of 100 random portfolios." That sounds like p < 0.01. But it isn't, because:

  1. The "best" model was already cherry-picked from 72 tries (so the framing should have been "best of 72 trials beat the 100th percentile" — which happens 97.5% of the time under no skill).
  2. 100 random portfolios is a very small sample for the tail percentile.
  3. Random portfolios in the same momentum-prefiltered universe inherit a lot of the model's exposure.

The correct version of this test is Hansen's Superior Predictive Ability (SPA), which is implemented in our pipeline. Running it on the realistic-cost data gives a p-value > 0.05.

The statistical bottom line

The honest interpretation is: this strategy might have a real but small edge, OR it might have no edge at all. Within the noise band, we cannot distinguish those two hypotheses from one run on 7 years of data. To distinguish them, we'd need either (a) much more data, or (b) a held-out 2025 lockbox that we promised in advance to use exactly once. We have the infrastructure for both, but we haven't done them yet.
